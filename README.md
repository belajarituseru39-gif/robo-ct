# Petualangan Nalar

Gim edukasi berpikir komputasional untuk murid kelas 5 SD.

## Cara menjalankan

Buka `index.html` di peramban.

## Menerbitkan dengan GitHub Pages

1. Buka **Settings → Pages** pada repositori.
2. Pilih **Deploy from a branch**.
3. Pilih branch `main` dan folder `/(root)`, lalu simpan.

Aset karakter berada di folder `assets/`.
